## 원문 보존 범위

이 문서는 현재 보고서 작성 및 백업 요청 시점에 접근 가능한 원문 prompt를 JSONL 형식으로 그대로 보존한다.
GREEN 구현을 수행한 step-by-step parent transcript 원문은 현재 subagent 입력에 제공되지 않았고, 접근 가능한 transcript 검색에서도 별도 GREEN parent 원문을 확인하지 못했다.
따라서 아래에는 parent가 report-backup-agent에 전달한 현재 요청 원문 JSONL을 변형 없이 보존한다.
요약본을 새로 작성하지 않았으며, 현재 접근 가능한 원문 범위의 한계는 작업 보고서에도 명시한다.
