## 원문 보존 범위 고지

이 문서는 `보고서작성 및 백업` 요청 시점에 subagent가 전달받은 사용자 요청, 작업 흐름 요약, 현재 저장소 상태, 도구 실행 결과를 가능한 한 원문에 가깝게 보존한 prompt export이다.

제약:

- 이 subagent는 parent agent의 전체 시스템 프롬프트, 모든 중간 응답, 모든 도구 실행 원문에 직접 접근할 수 없다.
- 따라서 이 파일은 제공받은 대화/작업 흐름과 현재 저장소에서 확인한 사실을 기반으로 작성되었다.
- 이 파일은 "요약없는 전체 대화내용"이라고 주장하지 않는다.
- 원문 접근이 제한된 부분은 제한 사실을 명시하고, 존재하지 않는 실행 결과나 테스트 통과를 기록하지 않는다.

## 현재 백업 요청 원문에 가까운 기록

사용자는 다음 조건으로 보고서 작성 및 백업을 요청했다.

- UnitConverter 프로젝트 `e:\dev\unit_converter_13`에서 보고서 작성 및 백업을 수행한다.
- 보고서/백업 에이전트는 계획 문서나 브랜치 전략 문서를 필수 참조 기준으로 삼을 필요가 없다.
- 이번 작업에서 생성/수정된 산출물로 `docs/branch-strategy.md`, `docs/stories/c03-meter-feet-yard-conversion.md`를 변경 파일 목록에 포함할 수 있다.
- 계획 파일 `c:\Users\disab\.cursor\plans\branch_strategy_a3fd17e7.plan.md`은 참조만 되었고 수정하지 않았으며 커밋 대상이 아니다.
- `git reset --hard`, force push, 임의 rebase를 하지 않는다.
- 비밀 파일 `.env`, credentials 등은 커밋하지 않는다.
- 사용자가 만든 관련 없는 변경은 되돌리지 않는다.
- `/prompt` 폴더에는 다음 일련번호 파일을 생성한다.
- 전체 raw 원문에 접근할 수 없는 한계를 파일에 명확히 남긴다.
- 요약본을 "요약없는 전체 대화내용"이라고 속이지 않는다.
- `/report` 폴더에는 같은 일련번호의 report 파일을 생성한다.
- 보고서에는 작업 목적, 변경 파일, 요구사항 연결, 테스트/검증 결과, 미완료 항목, 다음 단계, 커밋 해시와 원격 업로드 결과를 포함한다.
- 관련 파일만 stage 한다.
- 커밋 메시지는 변경 목적이 드러나게 작성한다.
- 커밋 후 현재 브랜치 `RED`를 `origin`에 push한다.
- push 실패 시 원인과 필요한 사용자 조치를 보고한다.

## 커밋 전 주의 사항

- 비밀 파일, `.env`, credentials 파일은 변경 목록에 나타나지 않았다.
- 계획 파일은 저장소 변경 목록에 포함되지 않았고 커밋 대상에서 제외한다.
- 구현 코드와 테스트 코드는 이번 변경 범위에 포함되지 않는다.
- Catch2/CMake 테스트 통과를 보고하지 않는다.
