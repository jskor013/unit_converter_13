## 2. 테스트 계획서 작성 요청

### 사용자 요청

```text
[P] 테스트전문가 입니다.
[C] C++17, CMake, Catch2
[T] 선택한 샘플 예제(meter→feet 변환)를 기반으로 테스트 계획서를 작성해줘.

    포함 항목:
    - Catch2 기반 단위 테스트 범위/우선순위
    - 경계값 케이스 목록:
        · value = 0 (영값 변환)
        · value = 매우 큰 수 (오버플로 위험)
        · value < 0 (음수 입력 정책)
        · 소수점 파싱 실패 ("meter:abc")
        · ":"없는 입력 (형식 오류)
        · 없는 단위 ("parsec:1.0")
    - 예외/특이 케이스 목록
    - 커버리지 목표 (Domain 95%+ / Boundary 85%+)
    - # gcov / lcov / gcov UnitConverter.cpp 측정 전략

[F] Markdown 문서. docs폴더에 test_plan.md로 저장.
```

```text
# Test Plan: Meter to Feet Conversion

This test plan defines the Catch2-based test scope for the selected sample feature: `meter -> feet` conversion.

The target business rule is:
1 meter = 3.28084 feet

Primary sample:
Input:  meter:2.5
Output: 2.5 meter = 8.202100 feet

P0: Core Domain Conversion
- Convert positive meter value to feet: `meter:2.5` -> `8.202100 feet`
- Convert one meter to feet: `meter:1` -> `3.280840 feet`
- Preserve source amount and unit in output

P1: Boundary and Validation
- `meter:0`
- `meter:1000000000000`
- `meter:-1`
- `meter:abc`
- `meter`
- `parsec:1.0`

Coverage Goals:
- Domain: 95%+ line coverage
- Boundary: 85%+ line coverage
- Branch coverage: 85%+ recommended

gcov / lcov Measurement Strategy:
- cmake coverage build
- ctest coverage run
- gcov UnitConverter.cpp
- lcov capture and genhtml report
```
