## 5. PRD/README/Agent 설정 반영 내용

### PRD 기반 요구사항 반영

대화 컨텍스트에서 Phase 5 PRD는 다음 계약을 중심으로 작성되었다.

- 입력 형식: `<unit>:<amount>`
- 기본 단위: `meter`, `feet`, `yard`
- 기준 비율:
  - `1 meter = 3.28084 feet`
  - `1 meter = 1.09361 yard`
- feet와 yard 간 변환은 meter 기준값을 경유
- 음수 입력은 `NEGATIVE_VALUE`로 거부
- 미지원 단위는 `UNKNOWN_UNIT`으로 거부
- 출력에는 원 입력 값과 원 입력 단위 보존
- C++17, CMake, Catch2 기준
- BCE 레이어와 OCP/SRP 원칙 반영

### README 반영 내용

현재 저장소의 `README.md`에는 다음 요구사항이 확인된다.

- 사용자가 입력한 길이 `단위:값` 기반 변환
- 새 단위 추가 시 기존 코드 변경 최소화
- 각 단위 변환 로직 테스트 검증
- meter/feet/yard 기본 단위
- README 기준 비율
- 입력 값 검증
- 설정 외부화
- 동적 단위 등록
- JSON/CSV/표 출력 포맷 선택

주의:
- 대화 중 `docs/PRD.md`와 확장 README 생성 및 README To-Do 추가가 보고되었으나, 현재 subagent가 확인한 작업트리에는 `docs` 폴더와 확장 README 내용이 보이지 않는다.
- 따라서 본 보고서는 “대화상 수행 이력”과 “현재 저장소에서 실제 확인된 파일”을 분리해 기록한다.

### Agent 설정 반영 내용

`.cursor/agents`에 다음 역할이 구성되어 있다.

- `report-backup-agent`: `보고서작성및백업` 요청 시 prompt/report 생성, commit, push 수행
- `cpp-qa-test-expert`: 테스트 코드 작성·수정, 테스트 보고서 담당. 구현 코드 본문 접근 제한
- `cpp-development-expert`: C++ 기능 구현·리팩터링 담당. 테스트 코드 접근 금지
- `project-manager-lead`: PRD, To-Do, 사용자 요구 대응, 문서 관리, 작업 조율 담당
