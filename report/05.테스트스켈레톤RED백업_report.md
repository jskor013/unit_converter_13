## 6. 미완료 항목 및 리스크

- 실제 `parse`, `convert`, `convertAll`, `registerUnit`, `loadConfig`, `format` 구현은 아직 없다.
- 현재 테스트는 전부 명시적 `FAIL("RED");`이므로 요구사항의 상세 기대값을 검증하지 않는다.
- clangd include 경로 진단은 IDE 설정 또는 compile commands 연결 문제일 수 있으나, CMake 빌드는 통과했다.
- 다음 GREEN 단계 전까지 이 테스트는 통과하면 안 되는 RED 산출물이다.
